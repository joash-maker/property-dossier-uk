Privacy

Last updated: 8 September 2026

Public website

The public Property Dossier Studio website is an information site. It does not currently contain a web enquiry form or create a public customer account. Demo requests are sent by email using your own email application.

Pilot workspace

Property Dossier Studio is currently a controlled pilot product. Access to the private Studio is restricted. Pilot data should be limited to information needed to test the agreed workflow, and anonymised or redacted examples are preferred until a formal client pilot is agreed.

Contact

For privacy questions, contact hello@mediahubink.com. Property Dossier Studio is a Mediahubink product.

This page is a plain-language pilot notice and is not a substitute for a client-specific data processing agreement where one is required.
